# Política Transparente 🇧🇷

&gt; **O que seu representante prometeu vs. o que ele realmente fez?**

Plataforma colaborativa e sem fins lucrativos para monitorar a atuação 
de deputados federais e senadores brasileiros durante seus mandatos.

## ✨ O que faz

- 📋 **Cadastro de promessas** de campanha (com fonte e verificação)
- 📜 **Proposições apresentadas** — via API oficial da Câmara e Senado
- 🗳️ **Votações nomeadas** com análise de coerência
- 💰 **Gastos do gabinete** em tempo real
- 📊 **Score de coerência** entre discurso e ação

## 🗂️ Fontes de dados

- [API Dados Abertos da Câmara dos Deputados](https://dadosabertos.camara.leg.br/)
- [API do Senado Federal](https://www12.senado.leg.br/dados-abertos)
- [Base dos Dados](https://basedosdados.org/)
